How this list was made

  • Checked in the source. Every entry was confirmed in the project's own package.json on its default branch in October 2026, and each name links to that file.
  • Runtime dependencies only. A library used only in a project's tests or build tooling is not counted. Miniflare is the one exception: it lists postal-mime for its build and ships it bundled inside its own code.
  • Public code only. Most software is private, so this is a small sample of where the libraries run, not a census.
  • No endorsement implied. Company and product names are trademarks of their owners and appear only to say where the code is used. To correct or remove an entry, email info@emailengine.app.
